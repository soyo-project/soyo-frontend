- CSS3
- JavaScript (Vanilla JS)

## 🚀 실행 방법

> 백엔드 서버가 먼저 실행되어 있어야 합니다. ([백엔드 실행 방법](https://github.com/soyo-project/soyo-backend))

**방법 1. HTML 파일 직접 열기**
```
pages/login.html 파일을 브라우저에서 열기
```

**방법 2. VS Code Live Server 사용**
```
1. VS Code에서 Live Server 확장 설치
2. pages/login.html 우클릭 → Open with Live Server
```

## 🌟 주요 기능

- 🔐 회원가입 / 로그인 — 아이디, 이메일, 닉네임, 학교 입력으로 회원가입, JWT 토큰 기반 인증
- 👤 프로필 관리 — 닉네임, 학교, 프로필 사진 수정
- 📝 게시글 작성 — 사진 최대 5장, 제목, 내용, 태그, 거리/소요시간, 출발지/도착지 입력
- 🔍 게시글 조회 — 전체 목록, 태그 필터, 검색, 공개 범위(전체/학교/나만보기) 설정
- 🗺️ 지도 조회 — 카카오맵 기반 게시글 위치 마커 표시
- 📅 캘린더 조회 — 날짜별/월별 내가 올린 게시글 조회
- 🤍 좋아요 / 북마크 — 게시글 좋아요 및 북마크 토글
- 👥 그룹 — 그룹 생성/참여(코드 방식), 그룹 피드 조회
- 📤 게시글 공유 — 내 게시글을 그룹에 공유
- 📊 내 활동 — 내가 올린 코스, 좋아요한 코스, 저장한 코스 조회
